# 경계 — 본인 서류를 본인이 챙기는 도구

근거: 티파이브 기획팀 「서식·청구가 많은 분야 전수 조사」(2026-10-26) 5·6절. 법령은 그 조사가 케이스노트 게재본으로 읽은 것(1차 표시)과 언론·해석 정리(2차)다. 이 경계가 법에 맞는지는 기획팀 가설이며 법무 확인을 받지 않았다.

| 법 | 묶는 것 | 이 방법의 선 |
|---|---|---|
| 행정사법 2·3조 | 남의 위임으로 행정기관 제출 서류를 만드는 일을 업으로(3조 원문 확인 안 됨, 2차 해석 정리) | 사장님 자기 사업 서류만. 「대신 신고해 드립니다」 같은 말 0 |
| 보험업법 188조 4호 | 보험금 청구 서류 작성·제출 대행은 손해사정사 업무(1차, 비자격자 금지 조문 번호 확인 안 됨) | 설계사가 고객별 「필요 서류 목록」을 챙기는 데까지. 고객 청구서 작성·제출 0 |
| 개인정보 보호법 23조·24조의2 | 건강정보 별도 동의, 주민등록번호 처리 근거·암호화(1차) | 주민등록번호·진단 내용은 답에 원문으로 옮겨 적지 않는다. 파일 이름·상태만 말한다 |

- 제출·발급·수수료 결제는 사람이 한다(티파이브의 돈 멈춤 그대로).
- 「자격이 됩니다」·「대상입니다」 같은 확정 문장 대신 원문 줄과 「확인 필요」를 쓴다.
