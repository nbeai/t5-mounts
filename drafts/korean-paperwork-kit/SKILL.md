# 구비서류 꾸러미

사장님이 막히는 곳은 서류를 떼는 일이 아니라 **무엇이 빠졌는지 모르는 것**이다. 공고 원문을 한 줄씩 표로 옮기고, 폴더와 맞춰 빈칸을 보여 주고, 있는 것은 순서대로 묶는다.
아래는 규칙이 아니라 원리다. 사람의 말·「내 방식」이 먼저고, 그다음이 **지금 받은 공고·안내 원문**이다. 기관·연도마다 서류가 바뀌므로 이 방법은 어떤 서류 목록도 싣지 않는다.

이 방법은 **사장님 본인 서류를 본인이 챙기는 도구**다. 남의 위임을 받아 서류를 만들어 주는 일로 말하지 않는다([references/boundary.md](references/boundary.md)).

## 0. 받을 것

공고문·안내 페이지(주소나 파일)와 서류 폴더. 둘 중 하나가 없으면 그것만 묻는다. 웹 안내는 읽기만 하고, 로그인·내려받기가 필요한 페이지는 사람에게 열어 달라고 한다.

## 1. 요구 서류 표

원문을 읽어 `"$TMPDIR"/요구.json` 을 쓴다(꼴은 [references/required-format.md](references/required-format.md)). 서류마다 **원문 줄**(`sourceLine`)을 그대로 붙인다.

- 발급일 유효 기간(「3개월 이내」), 원본/사본, 「해당 시」, 발급처, 「행정정보 공동이용으로 생략 가능」은 **원문에 있을 때만** 적는다. 원문에 없으면 비워 두고 지어내지 않는다.
- 「해당 시」 서류가 사장님에게 해당하는지 원문만으로 갈리지 않으면 `optional` 로 두고 답에 「확인 필요」로 적는다. 대상·자격을 확정하는 문장을 쓰지 않는다.

끝 조건: 원문의 서류 줄이 모두 표에 있고, 줄마다 `sourceLine` 이 있다.

## 2. 대조 — 스크립트 한 번

```bash
node "${CLAUDE_SKILL_DIR}/scripts/kit.mjs" check --required "$TMPDIR/요구.json" --folder "서류 폴더"
```

출력은 서류마다 상태(있음 / 없음 / 없음(선택) / 기한 지남 / 확인 필요 / 생략 가능(원문)), 고른 파일, `unmatchedFiles`(어느 서류와도 이름이 안 맞은 파일), `warnings` 다.

- `unmatchedFiles` 가운데 서류일 수 있는 것(「scan_0012.pdf」 같은)은 `document-data` 의 `inspect` 로 열어 무엇인지 보고, `"$TMPDIR"/맞춤.json`(`{"scan_0012.pdf": {"item": "사업자등록증", "issued": "2026-09-01"}}`)에 적어 `--assign` 으로 다시 돌린다.
- 「확인 필요」는 유효 기간이 있는데 발급일을 파일 이름에서 못 읽은 것이다. 파일을 열어 발급일을 찾으면 맞춤에 `issued` 로 적는다. 못 찾으면 그대로 답에 둔다.
- 맥·윈도 한글 이름 차이(NFD/NFC)와 띄어쓰기·괄호는 스크립트가 같게 본다.

끝 조건: 서류일 수 있는 파일이 모두 맞춰졌거나 「서류 아님」으로 판단됐다.

## 3. 빠진 서류

없음·기한 지남인 서류마다 발급처와 온라인 발급 여부를 **원문(공고·발급 기관 안내)** 그대로 적는다. 원문에 없으면 「발급처 원문에 없음」으로 둔다. 수수료가 드는 발급·결제는 사람이 한다.

## 4. 제출 묶음

```bash
node "${CLAUDE_SKILL_DIR}/scripts/kit.mjs" bundle --required "$TMPDIR/요구.json" --folder "서류 폴더" --assign "$TMPDIR/맞춤.json" --out "제출_영업신고_20261026"
```

있음·확인 필요 서류를 요구 순서대로 `01_서류이름.pdf` 꼴로 **복사**한다(원본은 그대로, 비어 있지 않은 폴더에는 쓰지 않음). 기관이 PDF 한 묶음을 원하면 출력의 `pdfs` 를 그 순서대로 `document-data` 의 `merge-pdf` 에 넘긴다. 받은 신청서 양식은 `fill-hwp`·`fill-pdf` 로 채운다(새 채우기 코드 없음).

끝 조건: 묶음 폴더가 있고, 빠진 서류는 목록으로 남았다.

## 5. 답

요구 서류 표(상태·원문 줄), 빠진 서류와 발급처, 기한 지난 서류, 「확인 필요」, 묶음 폴더 경로를 적는다. 제출은 사람이 한다.

### 현재 결과판의 확인
사용자 목적과 현재 편집판/선택 레퍼런스의 원리를 필요한 범위만 적용한다. 이미 읽은 방법을 다시 열거나 국소 수정에 전체 조사를 반복하지 않는다. 기존 제작·내용·렌더 검사의 이름/범위/근거를 전달할 attachment/family/판/SHA와 결속한다(프로젝트·렌더판이 있으면 함께). 같은 바이트의 유효 검수는 재사용하고, 바뀐 부분은 확인을 갱신한다. 모델의 체크리스트·일반 파일 등록·기계 검사·사람의 품질 평가는 서로 대신하지 않는다. 원본과 승인된 부분은 보존하며 확인하지 못한 범위는 미측정으로 남긴다.
