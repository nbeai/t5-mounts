# 직원 서류

근로계약서와 임금명세서는 법이 서면으로 주라고 정한 문서다(근로기준법 17조·48조). 틀리면 임금 문제가 되니 **계산과 법정 항목 대조는 스크립트가, 조건을 묻고 문장을 다듬는 일은 모델이** 맡는다.
아래는 규칙이 아니라 원리다. 사람의 말·「내 방식」·전에 쓰던 계약서가 먼저다. 이 방법은 **사장님이 자기 사업장 서류를 직접 만드는 도구**이며, 노무 서류를 대신 만들어 주는 일로 말하지 않는다([references/boundary.md](references/boundary.md)).

## 0. 해마다 바뀌는 값 — 먼저 확인

최저임금, 4대보험 요율, 소득세 간이세액은 이 방법에 **들어 있지 않다**. 그해 값과 출처(고시·고지서 이름과 날짜)를 사람에게 받아 사실표 `rules` 에 넣는다([references/yearly-values.md](references/yearly-values.md)). 최저임금 값과 출처가 없으면 임금명세서 계산은 멈추고 「확인 필요」를 낸다 — 그 자리를 다른 해의 값이나 기억으로 메우지 않는다.

또 하나: **상시 5명 이상 사업장인지**(`rules.overtimePremium`). 연장·야간·휴일 가산(근로기준법 56조)이 여기에 달려 있다. 모르면 묻는다.

## 1. 근로계약서

조건을 `"$TMPDIR"/계약.json` 에 쓰고(꼴은 [references/facts-format.md](references/facts-format.md)) 한 번 돌린다.

```bash
node "${CLAUDE_SKILL_DIR}/scripts/payroll.mjs" contract --facts "$TMPDIR/계약.json" --out "$TMPDIR/계약명세.json"
"$T5_DOCUMENT_CLI" create-docx --spec "$TMPDIR/계약명세.json" --output "근로계약서_나알바_20261101.docx"
```

`type` 은 정규·기간제·단시간. 스크립트가 그 유형의 법정 서면 항목([references/law-items.md](references/law-items.md))을 표로 깔고 빈 칸을 「(미정)」과 `missing` 으로 낸다. `missing` 은 사람에게 묻고 채워 다시 돌린다. 1주 15시간 미만이면 주휴·연차가 적용되지 않는다는 경고가 나온다 — 그 칸에 그 사실을 적는다. 서명은 사람이 하고, 1부를 직원에게 준다.

끝 조건: `missing` 이 비었고 다시 읽은 글에 항목이 모두 있다.

## 2. 임금명세서·임금대장 (매달)

그달 근무 기록(엑셀·메모)에서 직원마다 시간 합계를 뽑아 `"$TMPDIR"/근무.json` 에 쓴다. 엑셀 근무표는 `document-data` 의 `inspect` 로 읽고, 날짜·시각 칸이 숫자(엑셀 날짜 값)로 보이면 날짜로 바꿔 센다.

```bash
node "${CLAUDE_SKILL_DIR}/scripts/payroll.mjs" wage --facts "$TMPDIR/근무.json" --out-dir "$TMPDIR/명세"
```

출력은 직원별 지급 총액·공제 총액·실지급액, `warnings`(최저임금보다 낮은 시급, 15시간 미만 주휴 제외, 공제 없음), `missing`, 그리고 `임금대장.xlsx.json`·`임금명세서_<이름>.docx.json` 명세 경로다. 명세마다 `create-xlsx`·`create-docx` 로 만든다. 금액은 이 계산만 쓰고 손으로 다시 셈하지 않는다. 계산 식은 명세서의 「계산 방법」 칸에 그대로 들어간다(48조 2항: 구성항목·계산방법·공제 내역).

끝 조건: 직원마다 명세서가 있고, `warnings`·`missing` 을 사람에게 알렸다.

## 3. 4대보험 신고 기한

```bash
node "${CLAUDE_SKILL_DIR}/scripts/payroll.mjs" deadlines --facts "$TMPDIR/입퇴사.json"
```

입사(취득)·퇴사(상실)마다 신고 기한(사유가 생긴 달의 다음 달 15일)을 낸다. 신고 제출은 사람이 4대보험 정보연계센터 등에서 한다. 신고에 넣을 값 표는 만들어도 주민등록번호는 답에 원문으로 옮겨 적지 않는다.

## 4. 답

만든 파일, 직원별 금액, 경고, 「확인 필요」(최저임금 출처·상시 5명 여부·공제액), 신고 기한을 적는다.

### 현재 결과판의 확인
사용자 목적과 현재 편집판/선택 레퍼런스의 원리를 필요한 범위만 적용한다. 이미 읽은 방법을 다시 열거나 국소 수정에 전체 조사를 반복하지 않는다. 기존 제작·내용·렌더 검사의 이름/범위/근거를 전달할 attachment/family/판/SHA와 결속한다(프로젝트·렌더판이 있으면 함께). 같은 바이트의 유효 검수는 재사용하고, 바뀐 부분은 확인을 갱신한다. 모델의 체크리스트·일반 파일 등록·기계 검사·사람의 품질 평가는 서로 대신하지 않는다. 원본과 승인된 부분은 보존하며 확인하지 못한 범위는 미측정으로 남긴다.
