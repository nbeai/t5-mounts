# 네이버 첫 페이지 점유 기록

키워드마다 **네이버 첫 화면에서 우리 상호가 들어간 콘텐츠가 몇 개인지** 매일 같은 규칙으로 세어 쌓는다. 숫자(순서·점유·순위)는 `scripts/naver-exposure.mjs` 가 정하고, 이 방법을 쓰는 쪽은 묻고·돌리고·설명한다. 숫자를 짐작해 말하지 않는다.

이 방법은 재는 일이다. 노출을 올려 주지 않는다 — 올리는 일(스마트플레이스 정보, 블로그 글)은 그 방법이 따로 있으면 그것을 쓴다.

## 어떻게 받는가 (사람에게 한 번 알린다)

- 스크립트가 **로그인 없이** 네이버의 공개 검색 화면을 직접 받는다. 사장님의 크롬·로그인·쿠키를 쓰지 않는다. 그래서 개인 맞춤이 섞이지 않은 결과를 본다.
- 모바일 화면과 PC 화면은 순위가 다르므로, 휴대폰과 PC의 기기 표시로 각각 받아 따로 센다.
- 키워드 하나에 네이버 화면 다섯 장과, 상호를 제목·요약·작성자에서 못 찾은 글의 본문(최대 20개)을 읽는다. 네이버 요청 사이는 3초, 다른 사이트는 1초 쉰다. 키워드 하나에 30초~2분.
- 자동으로 읽는 양을 작게 두는 방법이다. 키워드를 수십 개 넘게 넣으려 하면 걸리는 시간(30개면 15~30분)과 읽는 양을 먼저 말한다.
- 네이버 화면 구조는 바뀔 수 있다. 바뀌면 그날 기록이 「덜 읽음」이 되고 까닭이 남는다.

## 판정 규칙 (바꾸지 않는다)

- 통합검색·블로그 탭을 모바일과 PC에서 따로 본다.
- 광고·플레이스 영역·네이버 자체 묶음(AI 브리핑·관련 질문·관련 검색어·이미지·클립)을 뺀 **위에서부터 5개 콘텐츠**를 본다.
- 제목 → 요약 → 작성자 → 본문 순서로 대조 상호를 찾는다. 대조 상호가 여러 개면 **하나라도 있으면 점유**다. 띄어쓰기는 무시하고, 화면에 안 보이는 글자(주석·스크립트)는 세지 않는다.
- 플레이스: PC 지도 목록 순위(광고 제외, 50위까지), PC 통합검색 플레이스 영역 안 순위, 모바일 통합검색 플레이스 영역 안 순위.
- 남이 쓴 글이라도 우리 상호가 있으면 점유다. 우리 채널만 따로 보고 싶다고 하면 설정의 `ownChannels` 에 주소를 넣어 「우리 채널」 칸으로 가른다.

## 기록 폴더

기록은 한 폴더에 계속 쌓인다. 처음에 폴더를 하나 정하고(사람이 말한 곳, 없으면 문서 폴더 아래 `네이버-점유-기록`), **늘 그 폴더에서** 스크립트를 부른다. 설정(`exposure.config.json`)과 기록(`exposure-data/`)이 그 폴더에 생긴다. 다음 대화에서도 같은 폴더를 쓰도록 폴더 자리를 기억해 둔다.

```bash
cd "<기록 폴더>" && node "<이 방법의 폴더>/scripts/naver-exposure.mjs" <명령>
```

## 처음 한 번

1. 없는 것만 한 번에 묻는다. 설정 파일은 손으로 고치지 않고 명령으로 넣는다.
   - **대조 상호** — `brand add 상호 별칭…`. 옛 이름·바뀐 이름·재단이나 지점이 붙은 이름을 함께 묻는다. 하나만 넣으면 우리 글을 미점유로 세는 일이 흔하다.
   - **플레이스 등록 이름** — `place add 이름`. 상호와 다를 수 있으니 확인한다(비우면 대조 상호를 쓴다).
   - **검색 키워드** — `keyword add 키워드…`. 많으면 한 줄에 하나씩 적은 파일로 `keyword import 파일.txt`(`#` 뒤는 메모).
2. `run` 을 돌린다. 키워드마다 한 줄 결과가 나오고 `exposure-data/` 에 `daily.csv`·`contents.csv`·`report.html` 이 생긴다. 결과 줄과 그래프 화면을 보여 주고, `today` 로 어느 글이 몇 위인지 모바일·PC로 나눠 설명한다.
3. 상호 자체로 검색한 키워드의 통합 점유가 0이면 대조 상호·별칭이 빠진 것일 수 있으니 다시 확인한다.
4. 매일 받고 싶다고 하면 **티파이브 예약 작업**으로 하루 한 번 `run --missing` 을 건다(그날 아직 못 한 키워드만 한다). 시각은 사람이 고른다.

## 사람의 말 → 할 일

| 말 | 할 일 |
| --- | --- |
| 오늘 노출 어때? | 오늘 기록이 없으면 `run --missing`, 있으면 `today` 를 요약. 점유한 글이 어디서(제목·요약·작성자·본문) 걸렸는지까지 |
| ○○로 검색하면 우리 몇 개 떠? | `run --keyword "○○"` 뒤 모바일·PC 각각 설명. 설정에 없는 키워드면 계속 볼지 묻는다 |
| 모바일이랑 PC 차이 보여 줘 | `today` 의 화면별 목록을 모바일·PC로 나란히 |
| 그래프 / 달력 보여 줘 | `report` 뒤 `exposure-data/report.html` 을 연다 |
| 엑셀로 줘 | `daily.csv`(하루 요약)·`contents.csv`(글 목록) 자리를 알려 준다. 엑셀에서 바로 열린다 |
| 상호 넣어 줘 / 빼 줘 | `brand list` 로 지금 목록을 보여 주고 `brand add` 또는 `brand remove` |
| 키워드 넣어 줘 / 빼 줘 | `keyword add`·`remove`·`import` 뒤 바뀐 목록을 보여 준다 |
| 지난주보다 나아졌어? | `daily.csv` 에서 키워드별 점유 수를 날짜순으로 견주어 답한다 |
| 왜 「덜 읽음」이야? | 그날 `daily.csv` 의 「덜 읽은 이유」를 읽어 주고, `exposure-data/raw/날짜/` 의 화면을 풀어 `parse <파일> --screen total` 로 어느 블록이 비었는지 본다 |

## 결과 읽는 법

- 결과 한 줄: `통합 모바일 2/5 · PC 3/5 | 블로그 모바일 1/5 · PC 1/5 | 플레이스 지도 12위/340 · PC 통합 7곳 밖 · 모바일 통합 영역 없음`.
- 「50위 밖」은 지도 목록이 50곳을 넘어 읽은 범위 안에 없다는 뜻, 「7곳 밖」은 통합검색 플레이스 영역에 보인 업체 안에 없다는 뜻, 「영역 없음」은 그 화면에 플레이스 영역이 아예 없다는 뜻이다.
- `contents.csv` 의 「본문 읽음: 아니오」는 카페 글처럼 바깥에서 본문이 열리지 않아 제목·요약·작성자로만 판정했다는 뜻이다.
- 같은 날 여러 번 돌리면 CSV에는 시도마다 한 줄이 남고, 그래프와 달력은 그날 마지막 시도를 쓴다. 기록이 없는 날은 그래프 선이 끊긴다.

## 하지 않는 것

- 기록·CSV를 고치거나 지우기. CSV가 망가졌으면 `csv` 명령으로 기록에서 다시 만든다. 엑셀에서 고친 파일은 다른 이름으로 저장하게 한다.
- 캡차가 나온 뒤 바로 다시 시도하기. 그 자리에서 멈추고 사람에게 알린 뒤, 30분 넘게 쉬고 `run --missing` 으로 잇는다.
- 요청 간격(`delayMs` 3000) 줄이기, 판정 규칙 바꾸기.
- 받은 화면 원본(`raw/`)은 14일 뒤 스크립트가 스스로 지운다. 그 밖의 파일은 지우지 않는다.
