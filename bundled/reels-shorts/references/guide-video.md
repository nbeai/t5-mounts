# 가이드 영상과 필수 장면

화면 조작을 설명하는 가이드 영상이면 **화면 이벤트 표를 먼저** 만든다. 표는 원본 지문·원본 시작/끝·관측한 화면 동작·완료 신호·대응 편집 구간·효과음 여부를 가진다. 실제 입력이나 클릭이 보인 구간에만 효과음을 놓고, 동작 없는 구간은 추가 효과음 없이 둔다. 연결 완료와 연결 뒤 사용 예시는 다른 사건으로 적는다.

사람이 꼭 넣으라고 한 장면은 **필수 장면 표**에 원본 in/out과 결과 timeline in/out을 짝지어 적고, 내보내기 전에 모든 행을 대조한다. 원본을 교체하면 새 지문으로 이벤트 표를 다시 측정한다. 옛 원본의 절대 시각을 새 원본에 재사용하지 않는다. 결과를 원본과 함께 재생해 이벤트 앞뒤와 소리를 확인한 범위만 완료라고 말한다.

출력 성공과 검수 통과를 따로 쓴다. `deliverable`의 경고·미측정·실패가 있으면 실제 내용과 `renderedRevision`을 답에 남긴다. OCR 미확인은 글자 부재의 증거가 아니며, 마지막 무음도 그 자체로 결함은 아니다. 직접 듣지 않은 소리와 직접 읽지 않은 글은 확인 완료라고 말하지 않는다.
