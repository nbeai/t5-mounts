# 가격 비교 상식

쇼핑몰에서 값을 비교할 때 사람은 보통 이렇게 본다.

- **비교 기준은 목록에 적힌 최종가다.** 지금 담아 결제하면 내는 값으로, 「할인 적용가」라고 하면 대개 이 값이다. 목록 카드에 정상가·할인율·최종가가 함께 보이면 최종가를 쓴다.
- **카드·쿠폰·멤버십 할인은 조건이 붙은 값이다.** 「○○카드 8% 할인」, 「쿠폰 적용 시」, 「멤버십가」는 누구나 받는 값이 아니어서 최종가에 섞지 않는다. 필요하면 표에 「조건부 할인」으로 목록 문구 그대로 따로 적는다. 그 조건부 값을 알아보려고 상세 페이지를 다시 여는 일은 보통 하지 않는다.
- **같은 상품을 여러 판매자가 팔면** 최종가가 가장 낮은 하나를 그 상품의 값으로 보고, 판매자 이름을 같이 적는다.
- **가격대 조건은 최종가로 거른다.** 「5만원대」는 50,000~59,999원이다. 경계에 걸친 상품도 최종가로 넣고 뺀다.
- **후기 수·평점은 목록에 보이는 값을 쓴다.** 상세 페이지는 목록에 없는 사실(무게·사용 시간 같은 사양, 배송 조건)이 필요할 때 연다.
