# 티파이브 스킬 저장소

**한국형 AI 비서 티파이브**를 쓰는 사장님들이 더 좋은 환경에서 일할 수 있게, 티파이브의 작업 방법(스킬)을 모아 두는 공개 저장소입니다.

- **기본 탑재 스킬** — 티파이브에 처음부터 들어 있는 스킬을 그 판 그대로 공개합니다. 이미 들어 있으니 따로 설치할 필요는 없고, 어떤 방법으로 일하는지 누구나 읽어 볼 수 있습니다.
- **골라 넣는 스킬** — 필요한 사장님만 골라서 넣는 스킬입니다. 우리가 만들었거나, 남이 만든 것을 검수했거나, 티파이브에 맞게 고친 것만 넣습니다.
- **앞으로 만드는 스킬도 여기에 쌓입니다.** 넣는 법은 [CONTRIBUTING.md](CONTRIBUTING.md) 한 장에 있습니다.

공식 안내: https://t5.beai.kr/ · 저장소 주소 `nbeai/t5-mounts` 는 티파이브 앱이 이미 알고 있는 주소라 그대로 씁니다.

## 설치하는 법 (골라 넣는 스킬)

티파이브 대화창에서 말로 합니다. 따로 배울 것은 없습니다.

1. **주소로 넣는 경우** — 티파이브 대화창에 주소를 붙이고 「**이 기능 쓰고 싶어**」라고 말합니다.
   - 저장소 첫 주소 `https://github.com/nbeai/t5-mounts` 를 붙이면 **진열된 스킬(`skills/` 폴더) 전부**가 한 번에 들어갑니다.
   - 하나만 넣으려면 목록에서 그 항목의 주소(`https://github.com/nbeai/t5-mounts/tree/main/skills/<이름>`)를 붙입니다.
   - 검수 중인 스킬(`drafts/`)은 첫 주소로는 들어가지 않습니다. 미리 써 보려면 그 항목의 주소를 직접 붙입니다.
2. **파일로 받은 경우** — 받은 zip 파일을 대화창에 붙이고 「**이 파일로 기능 추가해 줘**」라고 말합니다.
3. 티파이브가 들이기 전에 그 기능이 **컴퓨터에서 프로그램을 실행하는지, 어느 사이트에 접속하는지**를 한 번 알려 줍니다.
4. 들어온 기능은 **설정 › 장착 목록**에 보이고, 거기서 끄기·켜기·빼기를 할 수 있습니다.

기본 탑재 스킬(`bundled/`)은 설치하지 않습니다. 이미 티파이브 안에 있고, 첫 주소로도 들어가지 않습니다.

## 안전 장치

- **검수 증명서** — 항목마다 `mount.json` 이 있습니다. 누가 만들었는지, 원본이 어디 있고 어느 판으로 고정했는지, 어떤 파일이 들어 있는지(파일마다 지문), 라이선스, 쓰는 권한(파일·프로그램 실행·인터넷·외부 전송·돈), 맥·Windows 확인 여부, 언제 무엇을 어떻게 확인했는지가 적혀 있습니다. 확인 규칙은 [CHECKLIST.md](CHECKLIST.md).
- **기본 탑재 공개본은 앱 판 그대로** — 어느 티파이브 판에 실렸는지와 그 판의 스킬 글 지문(`bundledIn`)을 적고, 검사기가 이 폴더의 스킬 글과 바이트까지 같은지 대조합니다.
- **서명된 목록** — 모든 증명서를 모은 `index.json` 에 전자 서명(`index.sig`, Ed25519)이 붙어 있습니다. 누가 목록이나 파일을 몰래 바꾸면 서명·지문이 맞지 않게 됩니다. 서명 확인 열쇠는 `keys/t5-mounts-public.pem` 입니다.
- **남이 만든 것은 출처를 밝힙니다** — 원본 주소·고정 판·라이선스를 적고, 사용권 전문을 항목 안 `NOTICE.md` 에 둡니다. 공개 재배포 허락을 확인하지 못한 것은 싣지 않습니다.
- **비밀값 0** — 키·비밀번호는 이 저장소 어디에도 없습니다. 키가 필요한 기능은 사용자가 티파이브의 키 입력 칸에 직접 넣습니다.
- 티파이브가 사용자에게 멈춰 묻는 일(백업 없는 지우기·돈이 나가는 일)을 몰래 건너뛰는 기능은 넣지 않습니다.

| **검수 통과(원형 그대로)** | 남이 만든 것을 그대로 두고 우리가 확인만 한 것. 원래 주소와 고정한 판을 함께 적어요 |
| **티파이브 수정판** | 남이 만든 것을 티파이브에 맞게 고친 것. 원래 주소와 **바뀐 점**을 함께 적어요 |

### 이름과 판

- 이름은 **한국어 표시 이름**(장착 목록에 보이는 이름, 예: 「홍보 이미지 세트」)과 **영문 짧은 이름**(폴더·주소에 쓰는 이름, 예: `promo-image-set`) 두 가지입니다.
- 항목마다 판 이력 `CHANGELOG.md` 가 있어 무엇이 언제 바뀌었는지 볼 수 있습니다.
- 기본 탑재 공개본의 판 번호는 그 스킬이 실린 티파이브 판입니다(예: 2.8.1). 티파이브 새 판이 나오면 그 판의 스킬로 공개본을 새로 옮깁니다.

## 관리하는 사람을 위한 안내

필요한 것: Node 20 이상(의존성 없음).

| 명령 | 하는 일 |
|---|---|
| `node tools/validate.mjs` | 모든 `mount.json` 을 스키마(`schema/mount.schema.json`)와 실제 파일 지문으로 검사 |
| `node tools/refresh-files.mjs <항목 폴더>` | 파일을 바꾼 뒤 그 항목의 파일 지문을 다시 적음(검수를 대신하지 않음) |
| `node tools/build-index.mjs` | 검사를 통과한 항목으로 `index.json` 을 만듦 |
| `node tools/sign-index.mjs --key <저장소 밖 비밀 열쇠>` | `index.json` 에 서명해 `index.sig` 를 씀 |
| `node tools/verify.mjs` | 항목 검사 + 목록이 지금 항목과 같은가 + 서명 확인 |
| `node --test test/*.test.mjs` | 서명 틀림·지문 틀림·항목 빠짐·기본 탑재 판 어긋남 등을 잡는지, 스킬 스크립트가 맞게 도는지 시험 |

서명 열쇠는 회사 서명 열쇠이고(열쇠 번호 `db1c1cdbb0266527`, 티파이브 새 판 알림과 같은 열쇠), 비밀 열쇠는 이 저장소 안에 두지 않습니다(도구가 저장소 안 경로를 거절하고, `.gitignore` 가 `*.pem` 을 막습니다). 열쇠 바꾸는 법은 [keys/README.md](keys/README.md).

폴더: `skills/`(진열된 작업 방법 — 저장소 첫 주소로 들어가는 것) · `drafts/`(검수 중·내림) · `bundled/`(기본 탑재 공개본) · `plugins/`(플러그인 묶음) · `mcp/`(연결) · `cli/`(프로그램) · `schema/` · `tools/` · `test/` · `keys/`. 자동 실행(훅)은 티파이브에 그 기능이 생기면 `hooks/` 로 둡니다.
