## 2026-10-26 정리 방식(오너 방향, 상담3 전달)

오너 원문: 「해당 저장소에는 어차피 우리가 인증하거나 검수하거나 만든 스킬만 넣을 거니까 우리식대로 정리를 잘 해 놓으면 될 것 같아.」

1. 기술 종류 폴더(`skills/`·`mcp/`·`cli/`·`plugins/`)는 그대로 두고, 사장님 일 기준 분류 칸 `category` 를 더했습니다: 홍보·콘텐츠, 문서·서식, 돈·장부, 웹 업무, 사진·영상, 컴퓨터 관리. `index.json` 에 분류 순서(`categories`)와 출처 표시 이름(`originLabels`)을 함께 실어 진열대가 그대로 읽습니다.
2. 출처 표시 세 가지: 「티파이브 제작」(`t5_made`), 「검수 통과(원형 그대로)」(`reviewed_upstream`), 「티파이브 수정판」(`t5_modified`, 바뀐 점 필수).
3. 기본 스킬 업그레이드(오너 결정: 이미 실린 스킬은 같은 이름 + 높은 판 번호로 창고에서 내보냄): 명세 칸 `overrides`(덮어쓰는 기본 스킬 이름·기본 판·바뀐 점·되돌리기)와 항목마다 `CHANGELOG.md`. 실제 덮어쓰기 동작은 연구 세션 확인 전이라 칸과 검사기만 두었습니다. 확인한 사실: 본선 기본 스킬 SKILL.md 머리말에는 판 번호 칸이 없어(본선 `c53ec733`, `refoundation/skills/` 폴더 32개 중 SKILL.md 가 바로 있는 28개 모두 머리말 version 칸 0), 기본 판은 티파이브 판 + SKILL.md sha256 으로 가리킵니다.
4. 이름 규칙: 한국어 표시 이름(`name`, 한글 필수) + 영문 짧은 이름(`id` = 폴더).
