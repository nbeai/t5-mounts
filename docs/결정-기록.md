## 2026-10-26 정리 방식

이 저장소에는 우리가 만들었거나 검수했거나 고친 것만 넣으므로 우리식대로 정리합니다.

1. 기술 종류 폴더(`skills/`·`mcp/`·`cli/`·`plugins/`)는 그대로 두고, 사장님 일 기준 분류 칸 `category` 를 더했습니다: 홍보·콘텐츠, 문서·서식, 돈·장부, 웹 업무, 사진·영상, 컴퓨터 관리. `index.json` 에 분류 순서(`categories`)와 출처 표시 이름(`originLabels`)을 함께 실어 진열대가 그대로 읽습니다.
2. 출처 표시 세 가지: 「티파이브 제작」(`t5_made`), 「검수 통과(원형 그대로)」(`reviewed_upstream`), 「티파이브 수정판」(`t5_modified`, 바뀐 점 필수).
3. 기본 스킬 업그레이드(이미 실린 스킬은 같은 이름 + 높은 판 번호로 저장소에서 내보냄): 명세 칸 `overrides`(덮어쓰는 기본 스킬 이름·기본 판·바뀐 점·되돌리기)와 항목마다 `CHANGELOG.md`. 실제 덮어쓰기 동작은 확인 전이라 칸과 검사기만 두었습니다. 확인한 사실: 티파이브 기본 스킬 SKILL.md 머리말에는 판 번호 칸이 없어, 기본 판은 티파이브 판 + SKILL.md sha256 으로 가리킵니다.
4. 이름 규칙: 한국어 표시 이름(`name`, 한글 필수) + 영문 짧은 이름(`id` = 폴더).

## 2026-11-21 티파이브 스킬 저장소로 키움

1. **새 저장소를 만들지 않고 이 저장소를 「티파이브 스킬 저장소」로 씁니다.** 이름(`t5-mounts`)과 주소는 티파이브 앱이 이미 알고 있어 바꾸지 않습니다. 앞으로 만드는 스킬도 여기에 쌓습니다(넣는 법은 `CONTRIBUTING.md`).
2. **넣는 범위는 기본 탑재 스킬과 골라 넣는 스킬입니다.** 사용자 한 사람이 배운 작업 방식 같은 개인 자료는 넣지 않습니다.
3. **기본 탑재 공개본(`status: "bundled"`)** 을 새로 두었습니다. 티파이브 2.8.1 에 실린 스킬을 그 판 그대로 공개하고, 실린 판·본선 커밋·SKILL.md 지문을 `bundledIn` 에 적습니다. 검사기가 이 폴더의 SKILL.md 와 바이트까지 같은지 대조합니다. 설치할 항목이 아니라 진열대의 「골라 넣기」에는 나오지 않습니다.
4. 기본 탑재 스킬 가운데 **우리가 만든 것과, 라이선스가 공개 재배포를 허락하는 남의 것**만 공개합니다(원본 주소·판·라이선스 표기와 사용권 전문 `NOTICE.md` 함께). 라이선스를 모르거나 재배포 허락을 확인하지 못한 것, 원본 판을 확인하지 못한 것, 따로 보호하는 기능 영역은 공개하지 않습니다.
5. **스킬 폴더를 상태로 나눕니다.** 티파이브는 저장소 첫 주소를 받으면 맨 위 `skills/` 안을 전부 한 묶음으로 들입니다. 그래서 `skills/` 에는 진열 항목만, 검수 중·내림은 `drafts/`, 기본 탑재 공개본은 `bundled/` 에 둡니다. 쓰지 않는 `hooks/` 자리 폴더는 뺐습니다(「아직 못 쓰는 부분」 표시가 붙음).
6. 공개 전에 스크립트 주석에 남아 있던 내부 작업 표식은 지웠습니다(코드 동작은 같음). 스킬 글(SKILL.md)은 앱 판 그대로입니다.
