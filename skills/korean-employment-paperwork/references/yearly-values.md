# 해마다 바뀌는 값 — 이 방법에는 숫자가 없다

아래 값은 이 방법 어디에도 숫자로 들어 있지 않다. 그해 원문에서 사람이 확인한 값을 사실표에 넣는다. 출처 칸이 비면 계산이 멈추거나(최저임금) 「(미정)」으로 남는다(공제).

| 값 | 사실표 칸 | 상태 | 어디서 확인하나 |
|---|---|---|---|
| 최저임금(시간급) | `rules.minimumWage`, `rules.minimumWageSource`(고시 이름·날짜) | **확인 안 됨 — 사용자 확인**. 2026년 고시 원문을 이 방법을 만들 때 보지 못함 | 고용노동부 최저임금 고시 |
| 4대보험 근로자 부담액 | 직원별 `deductions[]`(금액과 `basis`) | 요율을 싣지 않음 — 고지서·정보연계센터 계산 값을 넣음 | 4대보험 고지서 |
| 소득세·지방소득세 | 직원별 `deductions[]` | 간이세액표를 싣지 않음 | 국세청 근로소득 간이세액표 |
| 상시 5명 이상 여부 | `rules.overtimePremium`(true/false) | 사업장마다 다름 — 사람에게 묻는다 | 사업장 사실 |

왜 싣지 않나: 값이 해마다 바뀌는데 스킬 안의 숫자는 아무도 고치지 않으면 틀린 채로 남는다. 틀린 최저임금 하나가 임금 문제로 번지므로, 원문을 본 사람이 넣은 값만 쓴다.
