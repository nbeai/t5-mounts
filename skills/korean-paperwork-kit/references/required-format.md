# 요구 서류 표 꼴 (`kit.mjs --required`)

```json
{
  "title": "공고·안내 이름",
  "source": "공고 주소나 파일 이름",
  "items": [
    {
      "name": "서류 이름(원문 그대로)",
      "aliases": ["파일 이름에 흔히 쓰는 다른 이름"],
      "sourceLine": "원문 줄 그대로",
      "form": "원본 | 사본 | (원문에 없으면 비움)",
      "validDays": 90,
      "issuer": "발급처(원문에 있을 때만)",
      "optional": false,
      "exemptByDataSharing": false,
      "exemptLine": "공동이용 생략을 말한 원문 줄"
    }
  ]
}
```

| 칸 | 쓰는 법 |
|---|---|
| `name` | 원문 서류 이름. 파일 맞춤과 묶음 파일 이름에 쓰인다 |
| `aliases` | 같은 서류를 부르는 흔한 다른 이름(「보건증」 → 건강진단결과서). 원문에 없는 서류를 더하는 칸이 아니다 |
| `sourceLine` | 원문 줄. 비면 `warnings` 에 나온다 |
| `validDays` | 원문이 「발급일로부터 ○개월/○일 이내」라고 할 때만. 개월은 날수로 바꾸되(3개월 → 90) 그 사실을 답에 적는다 — 개월 계산 방식은 기관 안내를 따른다 |
| `optional` | 원문이 「해당 시」·「해당자에 한함」처럼 갈라 둔 서류 |
| `exemptByDataSharing` + `exemptLine` | 원문이 공동이용(열람 동의)으로 제출을 생략할 수 있다고 할 때만. 원문 줄 없이 켜면 `warnings` |

## 상태

| 상태 | 뜻 |
|---|---|
| 있음 | 이름이 맞는 파일이 있고, 유효 기간이 없거나 안에 있다 |
| 없음 / 없음(선택) | 맞는 파일이 없다(선택은 「해당 시」 서류) |
| 기한 지남 | 파일 이름(또는 맞춤 `issued`)의 발급일 + 유효 기간이 오늘보다 앞이다 |
| 확인 필요 | 유효 기간이 있는데 발급일을 모른다 |
| 생략 가능(원문) | 파일이 없지만 원문이 공동이용 생략을 말했다 |

같은 서류 후보가 여럿이면 파일 이름 날짜가 가장 최근인 것을 고르고 `note` 에 후보 수를 적는다.

## 시험 사례로 쓴 분야 (가상 자료)

- 일반음식점 영업신고 — 구청 안내 꼴(위생교육 수료증·건강진단결과서·임대차계약서 등). 가상 안내문.
- 보험 설계사의 고객별 청구 서류 목록 — 보험사 안내 페이지를 읽어 고객마다 「청구에 필요한 서류」 표를 만들고 고객이 보내 준 파일과 대조하는 데까지. **고객 대신 청구서를 쓰거나 제출하지 않는다**(boundary.md). 가상 보험사 안내문.
