# 색 쓰는 법 — 스킬 재료 (4판)

색 체계를 쓰는 판단의 길잡이. 예시는 `examples.md`, 근거는 `basis.md`.

## 1. 바닥 — 이 넷만은 지킨다
1. 글이 읽힌다. 본문 4.5:1, 큰 글·뜻 있는 도형·기능선 3:1 아래로 내리지 않는다. 사진 위 글자는 글자 바로 뒤에서 잰다.
2. 색만으로 뜻을 전하지 않는다. 이름표·기호(▲▼)·굵기를 같이 쓴다. 베리와 초록은 적록 색약에게 거의 같은 색(ΔE 2.0)이라 빨강·초록만으로 좋고 나쁨을 가르지 않는다.
3. 사용자의 지시와 브랜드 색이 먼저다. 이 체계는 그것이 없을 때의 재료다.
4. 사람이 직접 고른 색은 덮어쓰지 않는다. 대비가 모자라면 사실을 알린다.

## 2. 원리 — 왜 그렇게 보이나
- **작을수록 진하게, 넓을수록 옅게.** 넓은 면은 더 진해 보이고 가는 선·작은 글자는 묻힌다. 바탕은 25~150, 글자는 800·900, 작은 표식은 600 근처가 잘 맞는다.
- **진한 색이 하나면 바로 보이고, 여럿이면 다툰다.** 먼저 보여야 할 하나에 강조를 준다. 고급스러움엔 짙고 덜 진한 강조, 할인·마감엔 진한 색을 작게.
- **같은 색은 한 묶음으로 읽힌다.** 뜻이 다르면 다른 색, 같은 항목은 모든 그림에서 같은 색. 흑백으로도 위계가 보이면 튼튼하다.
- **색상은 가깝게, 명도 차는 크게** 하면 조화롭다. 웜 그레이 + 주 계열 하나 + 강조 하나가 무난한 시작. 따뜻한 바탕 옆 순수 회색은 차갑게 뜬다.
- **AI 티는 짝에서 나온다:** 크림+테라코타, 검정+형광 주홍·연두, 남보라 단추. 한쪽만 닮은 것은 괜찮다.

## 3. 비교·분류
- 하나 돋보이게: 그것만 강조, 나머지 회색. 둘 맞대기: 남색 대 호박. 전후: 같은 색 옅음→짙음.
- 서로 다른 항목: 남색·호박·하늘(색약에서도 서로 ΔE 15 이상) → 청록·베리는 이름표와 함께. 일곱이 넘으면 기타로 묶거나 나눠 그린다. 작은 표식 600, 넓은 면 150.
- 순서 있는 등급: 한 색의 옅음→짙음. 기준 위아래: 두 색 + 가운데 회색, ▲▼ 함께.
- 분류 속 강조 하나: 다른 항목은 옅게, 하나만 짙게.

## 4. 결과물별 출발점
- **글자·선·면:** 본문 900, 보조 800(600은 큰 글). 꾸밈선 200, 기능선 600. 바탕 25·카드 50·둘째 면 100·띠 150, 그림자보다 명도 층. 어두운 화면은 바탕 950·카드 900, 위층일수록 밝게.
- **캐러셀·발표·문서·대시보드:** 목적 조합(`purposes`)이나 업종 조합에서 출발. 차트는 강조 하나 + 회색 막대 + 숫자 이름표.
- **웹·카드·HTML:** `tokens.css`를 붙이고 `data-palette`로 고른다. 밝음·어두움은 시스템 설정을 따른다.
- **도표:** 마디 50·100, 테두리 200, 화살표 600, 핵심 마디 하나만 강조.
- **일러스트:** 주조색 하나 + 보조 둘이면 정돈돼 보인다. 바탕 톤을 결과물 바탕 단계에 맞추면 그림이 녹아든다. 「평면, 톤 다운」과 색 이름+hex로 말한다. 음식·사람 같은 사진풍 그림은 색을 바꾸면 어색해지니 그대로 둔다.
- **사진·영상 위 글자(릴스 자막·카드·모션):** 단순한 화면엔 그라데이션 덮개, 복잡한 화면엔 단색 띠. 영상에서도 강조는 한 번에 하나.
- **인쇄:** 진한 색은 한 단계 낮추고 작은 글자는 검정에 가깝게.

## 5. 재료는 출발점이다
조합·단계·비율(진한 면 10% 안팎 등)은 시작점이다. 사진·주제·사용자의 말에 이유가 있으면 벗어나고, 그때는 바닥 넷만 확인한다.

## 6. 내기 전에
1. 흐리게 보면 강조하려던 하나가 먼저 보이나? 2. 진한 색이 흩어지거나 큰 면을 차지하나? 3. 작은 글·가는 선이 밝은 곳 휴대폰에서도 보이나? 4. 색을 빼도 뜻이 남나? 5. 바탕·강조 짝이 AI 티를 닮았나?
