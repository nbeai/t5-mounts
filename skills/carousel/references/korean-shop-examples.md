# 한국 가게 캐러셀 사례 3쌍 (합성 — 실제 가게·사람·수치 아님)

같은 재료를 「글만 늘어놓은 장」과 「보이는 것을 더한 장」으로 나란히 둔다. 고를 길을 넓히는 사례이지 정답 틀이 아니다.
숫자·이름·날짜는 모두 예시이며 실제 일에서는 사장님 재료에 있는 것만 쓴다.

## 1. 사진 + 가격 — 동네 카페 가을 신메뉴

재료(사장님이 준 것): 신메뉴 사진 2장, 「밤 라떼 6,500원, 단호박 스콘 4,200원, 10/25까지 세트 1,000원 할인」.
사실표: 알려진 값 = 메뉴 이름 둘·가격 둘·할인 1,000원·마감 10/25 / 계산한 값 = 세트 9,700원(6,500+4,200−1,000) / 모르는 값 = 영업시간·재고 → 장에 쓰지 않는다.
색: 업종 조합 「카페·식당」(presets.json cafe) — 밝은 장 light, 사진 위 글 dark 의 scrim·photoText.

| 장 | 글만 늘어놓은 장 | 보이는 것을 더한 장 |
|---|---|---|
| 1 | 「가을 신메뉴 출시」 | 밤 라떼 사진이 장을 채우고 「올가을 첫 한 모금」 한 줄(사진이 주인공) |
| 2 | 메뉴 두 줄 설명 | 두 메뉴를 나란히 둔 카드 두 장(html): 사진 원·이름·가격, 가운데 「+」 |
| 3 | 「세트 할인 1,000원」 | 가격표 꼴: 10,700원에 줄 긋고 9,700원을 accent 로 크게, 아래 작은 띠 「10/25까지」 |
| 4 | 「방문해 주세요」 | 스콘 사진 일부(focus)를 다시 쓰고 「저장해 두고 이번 주에」 cta |

## 2. 과정·체크리스트 — 미용실 집에서 하는 두피 관리

재료: 원장님이 보낸 메모 「샴푸 전 빗질 1분, 미지근한 물, 컨디셔너는 끝에만, 말릴 때 찬바람 마무리」. 사진 없음.
사실표: 알려진 값 = 단계 넷과 그 순서·「1분」 / 계산한 값 = 없음 / 모르는 값 = 효과 수치·제품 이름 → 「몇 % 개선」 같은 말을 만들지 않는다.
색: 업종 조합 「미용·네일」(presets.json beauty) — 사진이 없으니 밝은 장(light) 바탕에 accent 한 색.

| 장 | 글만 늘어놓은 장 | 보이는 것을 더한 장 |
|---|---|---|
| 1 | 「두피 관리 방법」 | 「샴푸 전 1분이 다르게 만든다」 + 큰 숫자 「1분」 색면 |
| 2 | 네 단계 한 줄씩 | 1→2→3→4 단계 원과 화살표(html), 단계마다 짧은 동사 하나 |
| 3 | 「미지근한 물」 설명 | 온도 막대: 차가움·미지근함·뜨거움 중 가운데에 표시 |
| 4 | 「찬바람으로 마무리」 | 체크 목록 넷(☑) — 장 2의 순서 그대로, 마지막 줄 accent |
| 5 | 「예약 문의」 | 저장 아이콘 + 「저장해 두고 오늘 밤 해 보기」 |

## 3. 긴 원고 — 동네 책방 이번 주 신간 소개

재료: 책방 주인의 소개 글 600자(책 제목·작가·주인이 밑줄 그은 문장 하나), 책 표지 사진 1장.
사실표: 알려진 값 = 제목·작가·밑줄 문장(원문 그대로)·표지 / 계산한 값 = 없음 / 모르는 값 = 판매 순위·가격 → 쓰지 않는다.
색: 업종 조합 「공방·소품」(presets.json craft, 작은 가게 손맛) — 인용 장은 surface 바탕, 표지 장은 사진 위 dark.

| 장 | 글만 늘어놓은 장 | 보이는 것을 더한 장 |
|---|---|---|
| 1 | 「이번 주 신간」 | 표지 사진 + 주인이 밑줄 그은 문장을 따옴표 크게(원문 그대로) |
| 2 | 소개 글 요약 | 「이런 분께」 상황 셋을 작은 카드 셋으로(소개 글에 나온 상황만) |
| 3 | 작가 소개 | 작가 이름 + 소개 글의 한 문장, 옆에 세로 선과 작은 책 도형 |
| 4 | 「책방에서 만나요」 | 책방 위치 문장(재료에 있을 때만) + 「저장」 cta |

## 공통으로 보이는 것

- 장마다 눈이 먼저 닿는 것 하나가 있다: 사진·큰 숫자·카드·단계 도형·체크 목록·인용 따옴표·가격표 꼴.
- 꾸밈은 재료의 관계를 보이게 하려고 더한다(비교 → 나란히, 순서 → 화살표, 할인 → 줄 그은 가격). 재료에 없는 숫자·단계·후기를 꾸밈 때문에 만들지 않는다.
- 색은 업종 조합 하나를 골라 그대로 옮기고, 손으로 쓴 html 장도 같은 조합의 역할 색(bg·surface·accent·text)을 쓴다.
