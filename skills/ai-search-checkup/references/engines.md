# 볼 곳마다 무엇을 읽나

화면 생김새는 자주 바뀐다. 아래는 **무엇을 찾아 읽는지**이고, 단추 위치를 외우지 않는다. 화면에 보이는 이름·글자로 찾고, 못 찾으면 그 사실을 기록에 적는다(「나오지 않음」과 「못 읽음」은 다르다 — 못 읽은 줄은 `shown` 을 비우고 `note` 에 까닭).

## 공통

- 한 번 묻기 = 새 검색 또는 **새 대화**. 앞 대화에 이어 물으면 앞 답이 섞인다.
- 묻는 말은 질문 묶음 그대로, 글자 하나 바꾸지 않는다(다시 잴 때도 같게).
- 답 원문은 화면 글을 그대로 파일에 남긴다(`answers/<볼곳>-<질문번호>-<회차>.txt`). 기록에는 판정만.
- 「나왔다」: 우리 가게 **이름**이 답 본문이나 목록에 있음. 지점명·옛 이름도 같은 가게면 나온 것으로, 비슷한 이름의 다른 가게는 아님.
- 「묘사가 맞나」: 답이 말한 주소·영업시간·메뉴·가격·특징을 가게 사실과 대조. 틀린 것은 `wrong_facts` 에 「무엇이 → 실제」로.
- 「인용 출처」: 답이 링크·출처로 단 주소. 여럿이면 `|` 로 잇는다. 출처 표시가 없는 서비스면 비운다.
- 위치: 화면에 「현재 위치」·지역 표시가 있으면 그대로 적는다. 위치가 다르면 동네 질문의 답이 달라진다.

## 네이버

- **통합검색**: 맨 위 AI 요약 칸(있을 때)과 플레이스(지도) 목록. 플레이스 목록에서 우리 가게가 몇 번째인지는 적어도 되지만 판정은 「목록에 있나」로 한다.
- **가게 이름 검색**: 플레이스의 리뷰 요약(AI 요약) 칸이 있으면 그 글이 우리 가게를 어떻게 묘사하는지 — 상호명 검색에서만 나오는 칸이다.
- **지도**: 같은 질문을 지도 검색에 넣었을 때 목록.

## 구글

- 검색 결과 맨 위 AI 요약(있을 때)의 본문과 그 옆·아래 출처 링크, 그리고 지도 묶음(지역 가게 목록).
- 한국어 질문이면 한국어 결과 그대로 읽는다. 로그인 여부를 적는다.

## AI 대화 서비스

- 새 대화에서 질문 그대로 묻는다. 서비스가 웹 검색을 켜고 끄는 단추를 보이면 **켠 상태인지 기록**한다(꺼져 있으면 가게 정보가 오래됐거나 없다).
- 답 본문의 가게 이름들, 답에 붙은 출처 링크(각주·출처 목록·카드)를 읽는다.
- 답이 끝까지 나온 뒤에 읽는다(글자가 계속 흘러나오는 동안 읽지 않는다).
- 사장님 계정의 사용량을 쓴다. 사용 한도에 걸리면 거기서 멈추고 몇 번까지 했는지 적는다 — 한도를 피해 다른 계정을 쓰지 않는다.

## 기록 칸 (templates/observations-template.csv)

| 칸 | 뜻 |
|---|---|
| `when` | 물은 시각(YYYY-MM-DD HH:MM) |
| `round` | `before`(고치기 전) 또는 `after`(고친 뒤) |
| `engine` | 볼 곳 이름(사람이 고른 이름 그대로, 예: 네이버통합, 네이버지도, 구글, AI대화1) |
| `logged_in` | `yes` / `no` |
| `location` | 화면의 위치 표시(없으면 빈칸) |
| `query` | 질문 그대로 |
| `shown` | 우리 가게가 나왔으면 `yes`, 안 나왔으면 `no`, 못 읽었으면 빈칸 |
| `described_ok` | 묘사가 사실과 맞으면 `yes`, 틀린 데가 있으면 `no`, 안 나왔으면 빈칸 |
| `wrong_facts` | 틀린 사실(「영업시간 9시 → 실제 10시」) |
| `others` | 함께 나온 가게 이름(`|` 로) |
| `sources` | 인용 출처 주소(`|` 로) |
| `answer_file` | 답 원문 파일 경로 |
| `note` | 못 읽은 까닭 등 |
